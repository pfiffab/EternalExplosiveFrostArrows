# All Eternal Explosive Arrows

Adds explosive impact behavior to the existing Eternal Frost Arrow tiers while retaining their frost projectile visuals and ice damage. The Frost blast keeps its visual components and ice damage distribution while inheriting the explosive impact logic and configuration needed for explosive-arrow skill effects.

The mod applies explosive environmental damage and ranged/AoE classification to the existing arrows. The inherited impact logic enables Echoing Explosives and Shrapnel Blast; ranged/AoE classification supports Shell Shock. `TERRAIN_FRIENDLY_COMPATIBILITY` in `src/mod.lua` controls whether the Frost blast's terraforming child effect is disabled; leave it enabled when using Terrain Friendly Explosive Arrows. It does not add items, recipes, or custom resources.

Install this folder in the Enshrouded `mods` directory with the Enshrouded Mod Loader enabled. The companion **Eternal Explosive Arrows** mod handles the Eternal Ember Arrow tiers; both mods can be installed together.
