# All Eternal Explosive Arrows

Adds explosive impact behavior to the existing Eternal Frost Arrow tiers while retaining their frost projectile visuals and ice damage.

The mod applies explosive environmental damage, ranged/AoE classification, and terraforming to the existing arrows. It does not add items, recipes, or custom resources.

Install this folder in the Enshrouded `mods` directory with the Enshrouded Mod Loader enabled. The companion **Eternal Explosive Arrows** mod handles the Eternal Ember Arrow tiers; both mods can be installed together.
